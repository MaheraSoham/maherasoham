## Public code

### [JobTrack Pro](https://github.com/MaheraSoham/jobtrack-pro)

A job-application tracking demo for recording applications and reviewing their status. The repository includes a Next.js interface, Prisma/SQLite persistence, API handlers to create, list and delete records, and a status-chart dashboard.

**Stack:** Next.js, React, JavaScript, Tailwind CSS, Prisma, SQLite and Recharts.

**Scope:** a demo, not a production SaaS application. Its sign-in implementation is demo-only; the application API does not enforce authentication or per-user access.
